# homebrew-tap

Personal [Homebrew](https://brew.sh) tap for [pavel-gorlov](https://github.com/pavel-gorlov)'s tools.

## Install

```bash
brew install pavel-gorlov/tap/ai-dotfiles
```

## Formulae

| Formula | Description |
|---|---|
| [`ai-dotfiles`](Formula/ai-dotfiles.rb) | Package manager for Claude Code configuration |
